# CryptoCroc Strategy (kort)

Stages:
- RADAR: brede instap (we verzamelen data)
- BUILDUP: coin bewijst zich (timing + consistency + engine)
- ALMOST: bijna klaar (OB check mag)
- ENTRY: alleen als OB + engine gate + stage minima klopt

Belangrijk:
- Nieuwe coin komt **direct zichtbaar** in RADAR met RADAR-lock.
- Side = band, niet “ch24 >= 0”.
- ENTRY is streng: vm/vol hoger + minimaal 5 scans + OB bevestiging.
